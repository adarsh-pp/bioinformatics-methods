# 🧬 Bioinformatics Methods

A curated collection of commonly used bioinformatics commands and workflows for quick reference.

This repository contains practical command-line examples for routine genomics and transcriptomics tasks, including file handling, alignment, variant analysis, and quality control.

---

## 📂 Contents

- FASTQ utilities  
- BAM processing  
- Variant handling (VCF)  
- Nanopore data processing  
- Assembly  
- Annotation  
- Enrichment analysis  
- Quality control & coverage  
- Bash utilities  

---

## 🎯 Purpose

This repository is designed as a lightweight reference for commonly used bioinformatics operations, focusing on clarity and usability rather than detailed explanations.

---

## ⚠️ Notes

- Commands are provided as general examples  
- Replace file paths and parameters as needed  
- This is not a complete pipeline repository

Browse individual files for specific tasks and commands.
